# 设计审美启蒙工作台 · Daily Aesthetic Atelier

面向设计学硕士新生的每日审美训练应用：以「美术馆策展」的方式，每天推送五件经典设计案例，配合图文解析、观察练习与视频讲解，帮助初学者在二十个主题日的循环中建立设计史的坐标系与看作品的眼睛。

## 功能

- **每日五件经典** — 案例库共 100 件，覆盖 20 个主题日（现代主义起点、字体的世纪、海报黄金时代、椅子的一百年、灯具与光、信息与界面、中国设计与东方回响等），按日期自动轮换。
- **图文研习** — 每件案例含导览、三条设计要点解析与一项观察练习；15 件核心案例配手绘几何示意图，其余由按类别参数化的生成式 SVG 示意图呈现。
- **视频解析** — 每件案例附讲解视频应关注的大纲；一键跳转 B 站（中文检索词）或 YouTube（英文检索词）搜索；粘贴视频链接后自动转换为可嵌入的官方播放器地址（YouTube → youtube-nocookie 嵌入端点，B 站 → player.bilibili.com 外链播放器），支持 watch/短链/shorts/live/BV 号/av 号/分 P 等常见形态。
- **夜场加映** — 完成当日五件后可继续研习馆藏中未学过的案例，按 5 件一批加开，直至学完全部 100 件。
- **成就徽章** — 9 枚徽章：初次凝视、首日闭馆、三日连贯、七日成习、夜场常客、四分之一馆藏、半座美术馆、鉴赏家之眼、全馆巡礼。
- **学习足迹与复习** — 按日记录研习内容；点击主题或案例标题可重新进入专题复习页；已完成案例可经两步确认重置为待研习。
- **进度持久化** — 学习进度与视频链接自动保存（Claude Artifacts 环境使用 `window.storage`；独立部署时自动降级为 `localStorage`，见 `src/main.jsx` 兼容层）。
- 适配桌面与移动端，支持 `prefers-reduced-motion` 与键盘焦点样式。

## 本地运行

```bash
npm install
npm run dev
```

## 构建与部署

```bash
npm run build     # 产物输出至 dist/
npm run preview   # 本地预览构建产物
```

`vite.config.js` 已设置 `base: "./"`，`dist/` 可直接部署到 GitHub Pages 或任意静态托管。

## 技术说明

- React 18 + Vite，单组件架构（`src/DesignAestheticsWorkbench.jsx`），样式为组件内自定义 CSS，字体经 Google Fonts 引入（Noto Serif SC / Noto Sans SC / Archivo）。
- 案例数据、生成式示意图系统、链接转换器（`toEmbed`）、进度与徽章逻辑均在该文件内，便于整体阅读与二次开发。
